# Plasticity demo

Prints the declared parameters for model HB-NLP-REV-001. It does not launch Plasticity, build a mesh,
or run a flow solver.

## Declared engine parameters

Copied from the engine in code and from `Docs/Designs/HB-NLP-REV-001/`. These are declared inputs,
not measurements. No technology readiness level, efficiency, or solver-convergence figure is claimed.

- **Model ID**: HB-NLP-REV-001
- **Thrust**: 3,500,000 N (3.5 MN)
- **Specific Impulse**: 351.5 s
- **Chamber Pressure**: 280 bar
- **Expansion Ratio**: 28.5:1

## Running the demo

```bash
dotnet run
```
